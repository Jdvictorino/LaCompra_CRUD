## 📋 Requisitos Previos

- Node.js
- npm

---

## 📋 Instrucciones

### ⚙️ Instalación

1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.

### 🚀 Ejecución

1. Ejecuta el comando `node index.js` en la terminal.
2. Abre el navegador y ve a `http://localhost:4000`.
3. Agrega, edita, elimina y busca productos en la lista.
